# Project Connect

Project Connect is a Flutter-based communication application designed to connect **students and project guides** in one place. It allows students to communicate with their guides and share project-related documents and reports.

## 🚀 Features

* 🔐 User authentication
* 💬 One-to-one chat between students and guides
* 📄 Share project reports and documents
* 🔔 Push notifications
* 👤 User profile management
* 🔥 Firebase integration
* 📱 Clean and simple Flutter UI

## 🛠️ Technologies Used

* **Flutter**
* **Dart**
* **Firebase Authentication**
* **Firebase Firestore**
* **Firebase Realtime Database**
* **Firebase Cloud Messaging**

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/flutterwithajay/project-connect-chat-app.git
```

### 2. Navigate to the project

```bash
cd project-connect-chat-app
```

### 3. Install dependencies

```bash
flutter pub get
```

### 4. Configure Firebase

Connect the project to your Firebase project and make sure the required Firebase configuration files are available for your target platform.

### 5. Run the application

```bash
flutter run
```

## 🎯 Purpose

The main purpose of Project Connect is to make communication between **students and project guides** easier during academic projects. Students can communicate with their guides and share project-related reports and documents through the application.



This project is developed for educational and learning purposes.
